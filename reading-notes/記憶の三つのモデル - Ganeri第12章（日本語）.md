# 記憶の三つのモデル：現代科学・世親・ブッダゴーサ

Ganeri『Attention, Not Self』第12章「自己認識的意識と所有」の論点整理
（英語版：[Three Models of Memory - Ganeri ch12.md](<Three Models of Memory - Ganeri ch12.md>)）

---

## 0. 要点

- この箇所の対立軸は「科学 対 仏教」ではない。**「薄い一元モデル」対「厚い二元モデル」**である。この軸は伝統の境界を横切る。Ganeri の配置では、タルヴィングはブッダゴーサ側に、クラインは世親側に立つ。
- **世親＝クライン**：記憶は「貯蔵（阿頼耶識）」と「所有タグ付け（染汚意）」という二つのシステムの合成物である。機構の説明としては最も精緻で、R.B. と患者 B. の症例にきれいに当てはまる。ただし所有は捏造（分別）とされる。そのため、心的時間旅行（エピソード記憶・未来思考）そのものが迷妄の側に入ってしまう。
- **ブッダゴーサ（Ganeri の再構成）**：エピソード記憶とは、過去に対する自己認識的な**注意の仕方**である。「再び生きる」ことはあっても、自己表象や所有は要らない。付加的なシステムも置かない。
- Ganeri の判定では、世親の貯蔵は「薄すぎ」（手続き的自己感しか支えない）、末那識は「厚すぎ」（自己認識に不要な要求を課す）。

## 1. 比較表

|---|---|---|---|---|
| **エピソード記憶の構成** | 単一のエピソード記憶システムと、そこから立ち現れる自己認識的意識 | 二つのシステム：貯蔵と自己認識的検索（所有の標識づけ） | 二つの識：阿頼耶識（貯蔵）と染汚意・末那識（所有化） | 一つの働き：過去への自己認識的注意 |
| **貯蔵の担い手** | 記憶痕跡。ただし感じは痕跡そのものには「宿らない」 | 意味的貯蔵。所有の標識を持たない | 阿頼耶識。薫習（vāsanā）によって内容を保存しつつ刹那ごとに複製し、獲得時の時・仕方・場所という**視点的情報**も保存する | 明示的な貯蔵識を置かない（本章では主題化されない） |
| **所有感（我がもの性）** | 所有を独立の成分とはしない。想起の「現象的風味」が主題 | 自己認識の本質的機能。「私」タグ（行為者としての自己のタグ）の挿入 | 末那識が阿頼耶識を「我がもの」として把握することで生じる。ただし分別（vikalpa）であり、自己は実在しない | 不要。仮に所有感に当たるものがあるとしても、固有の現象性から派生するものとして説明すべきで、付加的な能力ではない |
| **自己感の種類** | 主観的時間のなかで持続する自己 | 二層：特性的自己知識（頑健）と、エピソード記憶内の行為者としての自己 | 二層：（i）阿頼耶識に伴う原初的で非エピソード的な自己感、（ii）経験主体としての自己表象（末那識） | 自己表象なしの主観性。主観性は経験の固有の現象性によって説明される |
| **過去性の源泉** | 自己認識的意識の現象的風味 | 自己認識的検索 | 内容が感官からではなく**貯蔵から**検索されること。視点的情報が現在の視点を上書きする | 出来事に注意を向ける自己認識的な**仕方**そのもの |
| **心的時間旅行の評価** | 人間に特有の高次能力 | 同左（所有を介する） | 自伝的記憶も未来志向的思考も**迷妄**（我癡・我見・我慢・我愛と相応する） | 正当な認知能力。所有を介さないので迷妄にならない |
| **R.B. の説明** | （Ganeri によれば）クラインの補足なしで理解可能 | 検索・所有システムが一時的に損傷し、貯蔵は無傷 | 末那識の所有化機能が事故以前の記憶について損なわれ、阿頼耶識は無傷（Ganeri による対応づけ） | 揺れがある（§3-c）。所有のない再体験の実例とも読めるし、真の自己認識的注意を欠いた「外的注意」とも読める |
| **患者 B. の説明** | — | 特性的自己知識が持続的自己感の「岩盤」になる | 阿頼耶識に基づく原初的で非エピソード的な自己感。理論の予測どおり | 本章では直接論じられない |

## 2. 各モデルの強みと弱み

### 現代科学（タルヴィング／クライン）

- **強み**：解離の症例（R.B.：所有を失い内容は保たれる、患者 B.：エピソードを失い特性的自己知識は保たれる）という経験的な支えがある。R.B. の回復が「一つずつ、やがて全体が」と進んだことは、所有がモジュール的な機能であることを示唆する。
- **弱み**：タルヴィング自身が、自己認識が脳活動から立ち現れる仕方は「神秘的」だと認めている。クラインの「私」タグは、記述のための名前であって、説明になっているとは限らない。

### 世親

- **強み**：
  1. 貯蔵（阿頼耶識）と所有化（末那識）を**別々の識**として立てる点で、クラインの二システム説を約1600年先取りしている。
  2. 薫習が**視点的情報**（いつ・どのように・どこで得たか）まで保存するという読みは、エピソード記憶の文脈依存性をうまく説明する。
  3. 熟睡など、知覚的な識が途切れる「間隙」をまたいで連続性を説明できる。
  4. 自己感の二層構造（非エピソード的な層と主体表象の層）によって、患者 B. を予測できる。
  
  記憶の解釈において唯識が「精緻」だと言えるのは、まさにこの機構的な解像度による。
- **弱み**：所有を捏造とする一方で、心的時間旅行には所有が必要だとも認める。そのため、**エピソード記憶そのものが迷妄**になる。修道論的には一貫しているが、認知理論としては、正常な想起と迷妄を区別できなくなる。さらに阿頼耶識は、筆者の bhavaṅga 批判と同型の「連続性の担い手」問題を抱える。

### ブッダゴーサ（Ganeri の再構成）

- **強み**：「再び生きること」と「所有」を切り分ける。そのうえで、前者だけを注意の仕方によって説明する。付加的な機構も自己表象も要らないので、存在論的なコストが最小になる。想起を迷妄から救い出せるので、修道論的にも健全である。ATB（attentive true belief）テーゼとも整合する。知識の身分を、命題的な正当化（ここでは所有の表象）ではなく注意的アクセスの質に置くからである。
- **弱み**：
  1. 「固有の現象性」は、説明というより説明項に名前を付けただけになっていないか。
  2. 貯蔵の問題が手つかずである。過去の内容は、何によって現在まで運ばれるのか。
  3. R.B. の位置づけが揺れる（次節）。

## 3. 論点（議論の入口）

**a. 軸は伝統を横切る**　タルヴィングとブッダゴーサ、クラインと世親がそれぞれ同じ側に立つ。したがって、Ganeri の議論は「仏教が科学を先取りした」という話ではない。**同じ対立が二つの伝統の内部で独立に生じている**、という構図として読める。

**b. 世親のジレンマ**　「所有は捏造である」と「心的時間旅行には所有が要る」の二つを同時に保持すると、記憶は迷妄になる。この帰結を避けるには、どちらかの前提を捨てなければならない。ブッダゴーサは後者を捨てた。唯識の内部では、転識得智（末那識が平等性智へ転じる）によって、所有なき想起がどう可能になるのかが問われることになる。

**c. Ganeri 自身の緊張（翻訳の訳注8）**　観察者視点の段落では、R.B. のエピソード記憶能力は「無傷」とされ、ブッダゴーサ説の**確証**として使われる。ところが最終段落では、R.B. の記憶は固有の現象性を欠くので「エピソード的ではない」とされ、**欠如の事例**として扱われる。どちらの読みを採るかで、ブッダゴーサ・モデルの経験的な支えの強さが変わる。

**d. 世親から見た R.B.**　末那識による所有化が純粋な迷妄なら、それを失った R.B. は解脱に一歩近いことになるのか。Ganeri の「迷妄ではなく心盲」という言い方は、この問いへの暗黙の答えになっている。所有の欠如は無我の智慧ではなく、単なる能力欠損だということである。ただし R.B. は現在の自己感は保っているので、末那識が全体として停止したわけではない。
  - *筆者の論点（2026-10-28）*：末那識の転依は自己感の単なる消失ではない。平等性智として、自己感を失わないまま自他を平等に見ることである。したがって R.B. は悟りではない。
  - *補強*：(1) R.B. は「MIT の学位を持つという事実」を所有しており、特性的・意味的な自己像はなお我として把握されている。末那識は働き続けていて、エピソード内容との結びつきだけが切れている。(2) 過去の場面が「他人に語られた経験」のように感じられるのは、過去の自己が**他者の側へ移された**ということである。これは自他の境界の引き直しであって、平等化とは逆向きになる。(3) 唯識はもともと「心の機能が止まっていても解脱ではない」状態を区別している（無想定。前六識は止まるが末那識は残り、外道の誤った涅槃とされる）。R.B. はその病理版として位置づけられる。(4) 歩けなくなったことに喪失感がないのは我愛の不在に見える。しかしそれは「所有していないから苦しまない」のであって、平等性智の「所有を見通したうえで苦しまない」とは構造が異なる。

**e. bhavaṅga テーゼとの接続**　ブッダゴーサ側は阿頼耶識を拒否する。では、過去の自伝的内容を現在まで運ぶのは何か。Ganeri がここで bhavaṅga に頼るなら、筆者の批判のとおり、阿頼耶識と同じ「連続性の担い手」問題が別の経路から戻ってくる。等無間縁（samanantara-pratyaya）を漸化式として読み、貯蔵を**器ではなく因果系列の傾向的性質**として捉えれば、阿頼耶識も bhavaṅga も置かずに、ブッダゴーサの薄いモデルを完成させられる可能性がある。この箇所は、それを論じるのに適した場所である。

**f. 次節への予告**　Ganeri は、ディグナーガがこの一人称的特徴を**再帰性**（svasaṃvedana, 自証）によって説明しようとすると予告している。次節では第四のモデルとして「自己知の再帰性モデル」が加わる見込みである。
