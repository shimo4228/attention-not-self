# Decision History（判断の経緯）

What was decided in this repo and why, one dated entry per file, numbered in sequence, written in the past tense.
Each entry is the judgment of the day it was written; the current design is whatever the essays, graph and code
are now, plus the author's current instructions. The `Status` line in an older entry is the state on that day.
A new decision may conflict with an older entry; the older entry stays as it is.

## Template

New entries use these sections: Date / Context / Decision / Review-when / Alternatives Considered / Consequences.
Decision is written in the past tense (what was done and why). Review-when is optional; if there is none, write
"None — record".

File name: `NNNN-kebab-case-title.md` (zero-padded 4-digit sequence).
