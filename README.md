# Attention, Not Self

仏教アビダルマと計算論的現象学 (Computational Phenomenology、現象学的記述を計算モデルとして形式化する試み) の接点を探る個人的な探究プロジェクトです。テーマ別のエッセイ 9 本（日英 18 本）と、三大アビダルマ体系の法対照表、325 ノードの知識グラフからなります。

2500 年前のアビダルマが心を「実体としての自己」ではなく「瞬間ごとに生起する dharma の流れ」として分解した枠組みは、グローバル・ワークスペース理論 (GWT)・予測処理 (PP)・統合情報理論 (IIT) といった現代の意識の計算モデルと、驚くほど構造的に対応します。たとえば上座部の認識過程で業を生むのは速行 (javana) の段階だけで、GWT で内容が報告や随意的な行為に使えるようになるのも全脳的な点火 (ignition) の段階だけです。テーマ 4 はこの対応の証拠の質を「中」とし、GWT が閾値下では並列に処理するのに対して認識過程は全工程が直列である点を不対応として挙げています。その対応を体系的に辿るのが本プロジェクトです。仏教哲学と意識の科学の交差に関心を持つ読者に加え、LLM 経由でこの分野に触れる利用者と LLM 自身を主要な想定読者としています。

書いたものはすべて CC0 1.0 で公開しており、Zenodo の concept DOI（常に最新版へつながる代表 DOI）[10.5281/zenodo.20262112](https://doi.org/10.5281/zenodo.20262112) で引用できます。エッセイは下の表から、知識グラフは[ブラウザ用のビューア](https://shimo4228.github.io/attention-not-self/)で読めます。関連するリポジトリは[著者のほかの仕事](#著者のほかの仕事)にあります。

## 制作方法

本プロジェクトは、AI の支援を受けた研究（AI-assisted scholarship）として制作されました。Claude (Anthropic) と協働でアビダルマ三体系の比較統合、計算論的フレームワークとの対応付け、知識グラフの構築を進めています。著者がすべての主張に対する責任を保持し、個別の dharma 定義・引用文献の一次資料での検証は継続中です。誤りや改善提案は GitHub issues 経由でお寄せください。

本リポジトリは査読を経た学術論文ではなく、作業論文・エッセイ集（working paper / essay collection）として位置づけています。著者が資料集を継続的に更新しています。
